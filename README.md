# COIS-3060-Workshop4
Book catalog system for Riverside Library
\#\# How to Use

\#\#\# Add a Book  
\`\`\`  
python add\_book.py  
\`\`\`

\#\#\# Search for Books  
\`\`\`  
python search\_books.py  
\`\`\`

\#\#\# List All Books  
\`\`\`  
python list\_books.py  
\`\`\`

\#\#\# Delete a Book  
\`\`\`  
python delete\_book.py  
\`\`\`

\#\# File Format  
Books are stored in \`books.txt\` with the format:  
\`\`\`
Title, Author, Year  
\`\`\`

\#\# Example  
\`\`\`  
1984, George Orwell, 1949  
To Kill a Mockingbird, Harper Lee, 1960  
Calculus For Dummies, Mark Ryan, 2016
\`\`\`
